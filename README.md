# 一起听音乐

Windows 桌面端多人同步听歌软件。通过 Radmin VPN 联机，一首歌只需要房间内任意一个人本地拥有，Host 接收并校验文件后分发给在线成员，所有人按同一条时间线播放。

## 直接运行

打包后的软件位于：

```text
dist\ListenTogether\ListenTogether.exe
```

可分发压缩包：

```text
dist\ListenTogether-Windows.zip
```

压缩包已经包含 VLC 运行库，不需要另外安装 VLC。

## 使用流程

1. 所有成员加入同一个 Radmin VPN 私有网络。
2. 打开软件，点击“添加音乐目录”并等待扫描。
3. 房主点击“创建房间”，填写房间名、显示名、口令和端口。
4. 房主点击“复制房间信息”，把 Radmin IP、端口和口令发给朋友。
5. 其他成员点击“加入房间”，填写相同信息。
6. 在本地音乐库双击歌曲加入共享歌单。
7. 所有在线成员准备好当前歌曲后，房间自动开始同步播放。

Windows 首次运行时可能询问防火墙权限，需要允许专用网络访问。

## 当前功能

- 本地音乐目录扫描、搜索和元数据读取。
- 重新导入目录时只显示当前文件夹中的歌曲。
- 支持一键把当前文件夹全部歌曲加入歌单。
- 本地音乐库支持多选，只把选中的歌曲加入歌单。
- 完整 SHA-256 文件身份校验。
- Radmin VPN 上通过 TCP 控制房间。
- 房间口令挑战应答。
- 多人加歌、删除、拖动排序和切歌。
- 重复歌曲会提示并拒绝加入；顺序播放完成后自动从共享歌单清理。
- 上一首使用隐藏历史记录，仍可回放最近播放的歌曲。
- 右侧显示房间实际听歌时长，暂停和等待时间不计入。
- 左右栏支持拖动调整宽度，并可单独隐藏和恢复。
- 共享歌单提供“删除选中”按钮，支持一次批量删除，Host 可删除全部歌曲，普通成员只能删除自己加入的歌曲。
- 在线成员区域显示所有已加入成员的名称。
- 支持顺序、列表循环和随机播放，播放模式按钮位于音量滑杆右侧。
- 单曲循环和列表循环都会重新加载播放器，修复循环后无声的问题。
- 共享歌单支持一键定位到正在播放的歌曲。
- 单源文件上传到 Host，再由 Host 分发。
- 任意在线成员缺少当前文件时全员暂停等待。
- 独立时钟同步、统一起播和播放漂移修正。
- 当前歌曲文件加载后，下一首会整首预加载并校验。
- 本机独立音量。
- 断线自动重连和房间关闭提示。
- 临时缓存固定保留上一首、当前和下一首三首完整歌曲。
- 退出房间、正常退出和异常退出后的缓存清理。
- 单实例运行，避免重复启动破坏缓存。
- 外观改为适配好的固定预设，包含浅色、暖色、冷色、薄荷、玫瑰、深色、深夜蓝和毛玻璃组合。
- 启动前直接恢复上次外观，避免颜色跳变。
- Windows 标题栏和应用主题同步。
- 支持普通、毛玻璃和透明玻璃窗口效果。
- 支持同目录 LRC 或音频内嵌歌词，在播放器中间滚动显示。
- 带时间轴的 LRC 会跟随播放进度自动滚动，所有歌词水平居中，当前行放大并加粗。
- 没有歌词时播放器中间只显示歌曲名称。
- 使用新的红色音符应用图标和简约线性音量图标。
- 删除当前歌曲或清空歌单时，播放器会立即停止旧歌曲。
- 主题和玻璃效果切换时会强制刷新列表与歌词区域，避免文字重影。

## 缓存

缓存目录：

```text
%LOCALAPPDATA%\ListenTogether\cache
```

会话缓存上限默认约为 1 GB。上一首、当前、下一首和正在传输的文件始终保留，已经下载过的歌曲会在额度内继续保留，空间不足时自动清理最久未使用的缓存。正常退出、主动离房和 Host 关房时会清理；程序异常退出时，下次启动会继续清理遗留文件。

## 已知限制

- 只支持 Windows 10/11 x64。
- 不同码率、不同编码的同一首歌会被视为不同文件。
- 房主退出后房间关闭，不自动迁移 Host。
- 播放同步默认只使用 seek 校正，不默认启用变速，避免未经验证的音高变化。
- 本次验证使用本机 TCP 集成测试和 Radmin 地址识别，尚未在两台实际 Radmin 电脑上做长时间实听。
